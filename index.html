What is the Travelling Salesman Problem?

The Travelling Salesman Problem (TSP) is a well-known optimization problem in Computer Science.


Given a set of cities and the distances between them, the goal is to find the shortest possible route that visits every city exactly once and returns to the starting city.

🏙️ Visit every city exactly once → Return to the starting city → Minimize total travel cost

🎯 Objective

Find the minimum-cost Hamiltonian cycle among all possible routes.

Branch and Bound Approach

🌳 Branch

Divide the problem into smaller possible paths by selecting the next city.

📏 Bound

Calculate a lower bound for the possible cost of each partial route.

✂️ Prune

Discard paths whose estimated cost is already greater than the best solution.

🏆 Optimal Path

Continue exploring promising paths until the minimum-cost route is obtained.

Branch and Bound Algorithm 

BranchAndBoundTSP():

    Start from the first city

    Generate possible next cities

    Calculate the current path cost

    Calculate a lower bound

    If bound >= best cost:
        Prune this branch

    Otherwise:
        Continue exploring

    When all cities are visited:
        Return to starting city

    Update the best route and cost

How does it work?

Branch and Bound explores possible routes while avoiding unnecessary paths using a cost bound.


If a partial route is already more expensive than the best complete route found so far, that branch can be discarded.


This pruning process reduces the number of routes that need to be explored compared with checking every possible route.

Key Concepts

🗺️ Hamiltonian Cycle

A route that visits every city exactly once and returns to the starting city.

🌳 State Space Tree

Represents the different possible routes that can be explored.

✂️ Pruning

Removes branches that cannot produce a better solution.

🏆 Optimization

Finds the minimum-cost route among all valid possibilities.

Complexity Analysis

⏱ Worst Case Time

O(N!)

The worst case may still require exploring many possible permutations.

💾 Space Complexity

O(N)

Recursive search requires space for the current route and visited cities.
